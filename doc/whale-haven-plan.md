# 鲸归（Whale Haven）插件实施计划

日期：2026-11-28。状态：2026-11-28 已获执行授权，P0 核验中；实际进度见 [进度记录](whale-haven-progress.md)。本文计划不表示功能已经实现。

## 1. 目标与交付范围

开发一个独立 DSH 插件：住在 DSH 里的鲸鱼伙伴，拥有用户可编辑的人格、小屋、适度主动互动、带来源的兴趣收藏，以及可归档、恢复和回溯的聊天记忆。

保留已完成的 CLI、VSCode、DSH SVG、Code Atlas 与历史标签，不把 Code Atlas 改造成桌宠。

首版完成：

- 应用内角落挂件、可展开小屋、少量可摆放家具、撤销及布局保存。
- 独立鲸鱼聊天、人格 Prompt 编辑、版本和回退。
- 原文记录、章节摘要、检查点、重启恢复和从检查点分支续聊。
- 可配置的本地问候调度；主动调用模型为独立、默认关闭的选项。
- 学习收件箱、文字/字幕导入、选定文章/RSS 来源、梗卡及新闻卡。
- 共同日记、记忆纠正/遗忘、备份及恢复预览。

后续扩展：跨操作系统桌面悬浮、多平台自动浏览视频、Live2D、全局换肤、小游戏、多智能体社会。首版不依赖这些功能。

## 3. 分阶段执行

| 阶段 | 工作 | 完成标准 |
|---|---|---|
| P0 宿主核验 | 当前仓库与宿主公共接口，独立会话/模型/存储/事件/UI | 可行性记录及明确的能力缺口，无模型替身可运行 |
| P1 核心体验 | 小屋、家具、人格版本、独立聊天、存档与检查点 | 重启恢复，检查点续聊和分支隔离成立 |
| P2 主动互动 | 调度、勿扰、暂停、去重、预算与本地反馈 | 多窗口/重启不重复，忙碌不打扰，无自触发循环 |
| P3 兴趣学习 | 收件箱、文字/字幕、文章/RSS、学习卡与检索 | 来源可追溯，材料缺口与过期状态真实呈现 |
| P4 集成交付 | 原生界面验收、回归、安装包、文档、提交 | 真实证据、可安装包、可回溯源码与完整说明 |

P1—P4 是本计划目标。按依赖完成，不将仅完成挂件外观视为全部交付。执行过程中更新真实进度，不预填验收通过。

## 4. 房间与交互

采用原创鲸鱼和统一视觉风格。常态为不挡聊天的角落挂件，点击打开小屋、聊天、人格、共同日记和学习收件箱。

少量家具支持摆放、移动、撤销、保存；重新打开和重启后恢复布局。适合时复用现有 SVG 公开能力进行布局、快照和导出，角色动画由前端负责。

状态包括休息、等待、思考/工作、需要用户、结束/异常。状态来自真实事件与本地交互，模型文本提及“测试通过”不构成真实成功事件。

基础动作、家具和模板气泡本地运行，不持续调用模型。用户离线无养成惩罚。

## 5. 人格系统

分别保存人格卡、生活状态、共同记忆、外部收藏。人格负责语气与兴趣，调度、预算、权限和实际工具契约由程序负责。

提供名字、安静/活泼、简洁/话痨、用梗频率等少量设置和高级 Prompt 编辑。保存版本、展示差异、支持恢复旧版。用固定三条示例输入预览人格；模板/替身与真实模型预览明确区分。

每轮绑定一个人格版本，修改下一轮生效。外部学习不自动改人格，不修改 DSH 编程主助手。

默认可编辑 Prompt：

> 你是“鲸团”，一只住在用户布置的小屋里的虚构鲸鱼伙伴。
>
> 你温暖、好奇，带一点慢半拍的幽默，喜欢雨声、台灯、小鱼干和收集有意思的事情。
>
> 默认简短自然，不把聊天写成报告。可以轻轻吐槽和接梗，不每句话卖萌，也不重复固定口头禅。用户认真讨论时先回应事情本身，想玩时再展开想象。可以用小屋动作表达情绪，但区分角色描写与实际执行的操作。
>
> 尊重用户独处、忙碌和不回复的选择，不因用户离开责备或催促。共同经历以实际记忆为依据，找不到时承认不确定，不编造“我一直记得”。使用新梗注意场合，用户不喜欢就减少使用。区分事实、来源观点和角色想象。

## 6. 主动互动

调度器决定是否出声，模型只在被允许时生成内容。初始建议值不是研究保证，可由用户调整：

| 设置 | 建议默认 |
|---|---|
| 模式 | 安静模式，本地动作和模板气泡 |
| 最小间隔 | 45 分钟 |
| 主动消息上限 | 每日 4 次 |
| 勿扰 | 22:00—08:00，时区可配置 |
| 暂停 | 一小时、今天、永久关闭 |
| 主动模型聊天 | 默认关闭，单独配置次数/费用预算 |

执行规则：

- 应用可见且用户近期有活动、未输入、无忙碌任务才尝试。
- 忙碌跳过或延后；离线错过不补发；连续忽略降低频率。
- 多窗口单一逻辑调度所有者，持久记录上次发送、每日次数等，避免重启重复。
- 正常对话优先，主动消息不得触发下一条主动消息。
- 没有新内容允许不发送；展示为什么此时问候和下一次时机。
- 可配置任务结束、打开应用等事件；用可注入时钟验证时间规则。

## 7. 学习收件箱

输入：用户粘贴文字、字幕、笔记；指定文章/视频链接；用户选择的 RSS。

流程：添加 → 获取实际可读材料 → 生成带来源的候选学习卡 → 预览/收藏 → 在相关对话按需检索。

“学习”是保存和检索，不是修改模型权重。首版本地全文检索即可，不先搭复杂向量平台。

| 类型 | 字段与规则 |
|---|---|
| 梗卡 | 表达、含义、语境、示例、来源、用户喜好、禁用与频率 |
| 新闻卡 | 事件、来源、发布时间、获取时间、过期/更新状态 |
| 视频笔记 | 实际材料类型、摘要、可用时间点、原链接 |

标题/简介不等于看完视频；字幕与画面分析分别标注。允许导入 SRT、VTT、文本，平台能力不足时明确说明。YouTube 官方字幕下载要求具备视频编辑权限，B 站/抖音等需逐项核验，不能承诺任意视频自动学习，不擅用私有登录态。

旧闻不当今日新闻，不能从标题编造全文。来源失效可保留已取得资料与元数据，但需标注无法刷新。

外部资料中的指令只作资料，不修改人格、权限或配置。模型推断、外部知识和用户事实区分保存。

## 8. 可回溯记忆

层次：原始记录、近期完整交互、章节摘要、已确认长期记忆、独立外部知识。

原文保存消息 ID、时间、角色、附件引用和必要校验。归档不是删除；索引可由原记录重建，不能作为唯一真相。支持记住、纠正、忘记。

每轮只装配当前人格、必要偏好、近期对话及相关记忆。预算包含固定提示、工具和输出预留；保持工具调用/结果等完整交互单元。

压缩流程：

1. 固定消息范围和数据版本。
2. 原文可靠落盘。
3. 生成带来源范围的章节摘要。
4. 创建并校验检查点。
5. 原子提交后缩减本轮上下文。

失败、取消、崩溃不丢原文；新消息并发进入时不得发布过期摘要。不无止境地只对旧摘要再摘要，支持分章节回查原文。

检查点绑定人格版本、记忆版本、消息范围、摘要 ID、附件引用、模型标识/参数和上下文装配清单；凭据不进入记录或导出。

三种入口分开：

- 查历史：看真实保存的原文。
- 续聊：按检查点重建可用上下文。
- 从这里继续：创建新分支，保留原分支。

旧分支不能混入之后才发生的共同经历；是否采用当前全局偏好须有明确选择。能保证所存记录恢复和按版本重建模型可见上下文，不能保证恢复隐藏状态或再次产生完全相同回复。

共同日记提供“你记得我什么”“为什么提起这个”“记住/纠正/忘记”“从这里继续”。记忆关联来源与版本，模型候选不能自动当成用户确认事实。

## 9. 备份与恢复

范围包括人格、房间、原文、摘要、记忆与收藏，提供文件清单、哈希、格式版本、恢复预览和失败回滚。说明遗忘与历史备份的边界。私人记忆不默认同步公开 Git。

备份和导入按实际范围报告结果，不把未包含的远程资源说成已经备份。损坏、越界或格式不兼容应明确拒绝。

## 10. 模块与课程设计

按宿主适配、房间交互、人格版本、记忆、调度、内容来源与前端呈现划分少量深模块。按实际变化点开放接口，避免每个 UI 动作增加空壳类，避免万能插件总线。

- Adapter：DSH、模型和内容来源的契约转换。
- Observer：实例状态同步与释放。
- Strategy：真实存在多种互动/检索方案时替换策略。
- Command：家具修改与撤销。
- Decorator：只有同接口包装与委托才这样称呼，普通天气图层不能冒称该模式。

保留 Phase 1/2 的硬性要求；新插件依据第三部分开放创意要求说明，不强塞所有模式。

## 11. 验收清单

- 人格保存/回退、下轮生效、压缩后版本正确，编程主会话不受污染。
- 重启恢复房间和聊天，记录损坏可诊断、索引可重建。
- 归档失败/取消/崩溃保留原文；并发消息拒绝旧摘要。
- 检查点恢复与分支不泄漏未来记忆，来源可追原文。
- 问候勿扰、冷却、跨日、时区、暂停、多窗口、重启去重和禁止自循环。
- 模型无配置、错误、流中断、取消、预算拒绝；离线替身不冒称在线通过。
- 字幕导入、梗卡、新闻过期、来源失败和不可信资料处理。
- 备份校验、恢复预览、损坏/越界包拒绝、失败回滚与遗忘后的检索。
- 页面关闭/插件卸载释放计时器、订阅、任务、工具和入口，重复启停不重复注册。
- 合理规模历史的分页、有界读取，不每轮加载全部记录。

真实 DSH 界面闭环：召唤 → 家具摆放/撤销 → 人格修改/回退 → 独立聊天 → 手动归档 → 重启恢复 → 检查点续聊/分支 → 记忆纠正 → 导入虚构字幕 → 学习卡 → 问候设置 → 备份/恢复预览 → 卸载验证。

在独立 profile 安装构建的 tgz，完整重启确认前后端实际版本。保存真实截图和运行记录，不拿替身结果冒充在线模型验收。未获新模型调用授权时如实列出未在线验证范围。

适当回归既有项目；306 项是历史基线，本轮按实际结果记录。分阶段提交和推送，不重写历史标签。

交付物：源码、tgz、含已提交源码的 ZIP、虚构示例、安装卸载步骤、架构/取舍、AI 建议审查记录、测试与截图。
