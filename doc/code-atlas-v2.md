# Code Atlas 0.2：按任务阅读与核验代码

## 本次反馈与选择

用户反馈：依赖图过于密集，界面和源码区域太小，跳转后无法返回，import 证据不足以解释任务如何运行，AI 生成的代码量又超过人的逐文件核验能力。

因此采用“项目总览 → 任务导览 → 按需查看调用与源码”的阅读工作台。树用于找代码，图用于局部关系，模型负责解释一条有范围的任务路径；三种表示各有用途，不将整个项目压成一张巨图。

## 已实现的阅读路径

1. **项目总览**：目录模块与文件数、符号数、可能入口。入口只是启发式建议，优先本项目生产源码，不代表静态分析已经证明启动入口。
2. **文件导航**：按需展开符号、按名称或路径搜索、按符号类型筛选，分批显示文件。方法标签包含所属类/命名空间，避免一屏都是同名的 create/execute。
3. **关系浏览**：导入/继承/实现与调用参考分开。超过 12 个可见节点默认用清晰列表；图仍可手动打开、平移、缩放，导出继续复用原 SVG 能力。
4. **任务导览**：输入具体问题，由 DSH 默认模型生成步骤说明、后续分支和核验问题。每步必须关联给模型的真实代码节点；跨步或循环引用通过链接表示，不无限展开树。
5. **核验源码**：证据默认收起；需要时打开完整文件的 180 行上下文窗口，支持翻页、定位与字号调整。源码保持只读。
6. **阅读导航**：后退、前进、面包屑。历史包括选择、方向、层数、关系类型、搜索和源码显示状态；新分支移除旧的前进路径，最多保留 80 次访问。导航在源码核验成功后一次提交，失败不改变位置或关系设置。

界面提供“专注画布”，临时收起文件与源码区域。普通字号为 15px，图形标题为 16px，源码可在 12～22px 调整；长代码分页，不创建整份大文件的 DOM 行。

## 解释、事实与核验的边界

| 信息 | 产生者 | 能证明什么 |
|---|---|---|
| 文件、类、方法、源码范围与哈希 | TS7 适配器及 DSH FS | 某个快照中的声明和位置 |
| import / 类型结构 | TS7 符号解析 | 结构引用，不能证明执行先后 |
| calls / constructs | TS7 已解析签名或符号 | 静态调用/构造位置与声明目标；属性方法的动态实现仍未证明 |
| 导览正文与步骤分支 | 模型 | 任务解释与建议阅读路径，必须保留为模型推断 |
| 人工核验问题与勾选 | 模型建议 / 使用者 | 待检查内容与用户标记，不等于自动测试已通过 |

匿名回调有独立符号。回调正文中的调用不归给外层函数，避免错误暗示“注册回调就已经执行回调”。找不到目标的调用显式保留，不虚构函数实现。完整运行控制流、反射和外部服务行为不在静态调用参考的保证内。

任务上下文优先当前符号、文件中的真实调用目标、其内部符号以及任务关键词匹配。最多提供 24 个符号、42,000 字符正文和 240 个调用位置；每符号最多 5,000 字符，保留截断标志与未包含数量。入口文件只有 `new Host().run()` 时，会先跟随这个真实目标，避免用全项目随意同名 run/execute 代替它。

模型接收的源码被明确视为待分析数据。模型没有文件写入、执行或任意工具能力；生成文本不作为 HTML 或脚本执行。导览最多 16 步，引用必须属于当前快照与实际提供给模型的节点；步骤 ID 和后续引用也需有效。生成前、发布前和点击源码时核验内容。源码刷新后旧导览清除；取消、超时、会话关闭和卸载都会阻止迟到结果发布。

## 与课程模式和模块原则的对应

- **Adapter**：TS7 转源码事实、DSH FS 转 CodeSource、RemoteResult 转普通数据分别留在边界。此次补充所有远程方法的参数转发、失败与订阅释放测试。
- **Strategy**：依赖/上游读取仍由 ReadingStrategy 决定。关系种类先选取事实子集，不把运行逻辑解释硬塞入该算法。
- **Decorator**：标签继续保持同接口、持有上游与委托的包装结构；公开 API、已读、测试文件可以叠加，不把阅读标志写进 Shape。
- **Observer**：Workbench 通知实例订阅者，原生 watch 同步到 Controller，多个面板订阅同一实例；注销与取消有对应生命周期。
- **新增 GuideProvider**：只隔离“生成解释”这一真实变化点。DSH LLM 的配置、流式协议和错误由 DshGuideProvider 适配；导览校验不依赖具体模型。
- **信息隐藏与深模块**：编译器句柄、模型传输格式、工作区读取和 SVG 序列化各有归属。常用界面通过入口、生成、返回和查看源码操作完成阅读，不要求用户装配模式对象。
- **适度通用**：没有实现万能 IDE、可执行的模型脚本、自动重构或源码编辑器。新增代码集中在 DSH 扩展，原 CLI/VSCode 运行代码未修改；保留 Phase 1/2 回归和旧标签历史。

## 本次验证与当前限制

自动测试和安装检查的实际结果见 `code-atlas-verification.json`；本地测试使用无网络模型替身，不调用用户的付费模型。导览样例见 [box-creation-guide.md](../extensions/dsh-code-atlas/examples/box-creation-guide.md)，由本次助理阅读源码后编写，并经同一引用校验器检查，不冒充在线模型验收记录。
