# modified-star 标签

`TreeStarPlugin` 每次激活都创建独立的 `ModifiedStar` 实例。实例字段保存最近的成功保存/读入基准及节点内容索引，不使用模块级共享状态，不监听编辑命令，也不改变文档。

- init 尚未保存：根与新建节点立即标 `*`。
- 成功 save/read：更新基准，内容相同的节点不标记。
- 编辑后与基准不同：该节点及包含它的全部祖先标记；undo 内容回到保存点后消星，redo 后恢复。
- 删除与排序变化由祖先的子节点列表体现；跨父节点移动还改变节点的 parent 身份。
- 保存或读入失败：基准不变。将属性设置为原值不产生星号。
- 与 box 标签按注册顺序拼接，默认显示 `(box) *`；插件之间不互相引用。

标签对每行比较自身及后代的内容，并缓存保存基准的局部内容签名。没有增加事件总线或全局 dirty 集合。完整树在极端深链情况下会重复检查后代，最坏 O(n²)；CLI 规模下优先保持行为简单、正确。若未来实测有性能问题，应在插件内部引入渲染周期缓存，保留该接口和语义。

基准仅供只读比较，禁止插件改动 `TreeRow.document`、`TreeRow.saved` 或图形。编辑历史仍使用局部补偿，基准快照不参与 undo。

构建后独立验证：`node --test dist/test/tree-star.test.js`。
